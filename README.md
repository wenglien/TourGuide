# TourGuide - AI-Powered Smart Itinerary Planner

TourGuide is a modern, AI-driven travel planning application designed to help users create personalized, curated, and executable itineraries. Whether you're looking for a deep local experience or a quick city tour, TourGuide uses AI to craft the perfect journey for you.

## Features

- **AI Itinerary Generation**: Tell us your preferences, and our AI (powered by Groq/Llama 3) will generate a detailed multi-day plan.
- **Theme Trails**: Explore curated routes focused on specific themes like "Foodie Paradise," "Historical Deep Dive," or "Nightlife Explorer."
- **Smart Route Planning**: Optimize your travel route between multiple spots with AI-driven sequencing.
- **Budget Tracking**: Keep track of your estimated vs. actual spending in real-time.
- **Companion Mode**: Real-time monitoring of weather and crowd levels to suggest adjustments on the fly.
- **PWA Support**: Install TourGuide on your mobile device for a native-like experience.
- **Multi-language Support**: Fully localized in Traditional Chinese and English.
- **Export Options**: Save your itineraries as PDF or add them directly to your Google Calendar.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Vanilla CSS (Modern CSS with Variables)
- **Backend/Database**: Firebase (Firestore, Auth, Storage)
- **AI Engine**: Groq API (Llama 3.3 70B)
- **Maps**: Google Maps JavaScript API (Places, Geocoding, Distance Matrix)
- **Export**: jsPDF, html2canvas

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- A Firebase project
- A Google Maps API key
- A Groq API key


## PWA Installation

TourGuide is a Progressive Web App. You can "Add to Home Screen" on iOS (Safari) or Android (Chrome) to use it offline and with a native app feel.
